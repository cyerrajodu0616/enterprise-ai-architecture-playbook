# Assets

This directory contains source and rendered diagrams, images, and other media used by lessons, ADRs, case studies, cheat sheets, and system designs. Do not store generated build output or unrelated attachments here.

Use lowercase kebab-case names that identify the subject and version where relevant, such as `healthsure-v01-context-diagram.svg`. Prefer editable source formats, keep rendered variants consistent with their source name, and link assets from the document that explains their architectural meaning.
