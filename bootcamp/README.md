# Eight-Week Bootcamp

This bootcamp develops architectural judgment through a sequence of connected decisions. Each week advances the HealthSure case study and builds on the assumptions, ADRs, risks, and operating responsibilities established earlier.

## Sequence

1. [Knowledge Systems](week01-knowledge-systems/README.md) — decide how enterprise knowledge should be found, grounded, and evaluated.
2. [AI-Ready Data Foundations](week02-ai-ready-data/README.md) — make authoritative data usable, reproducible, and governed.
3. [Enterprise AI Platform](week03-ai-platform/README.md) — define shared platform boundaries without creating a delivery bottleneck.
4. [Models, Context, Tools, and Workflows](week04-model-context-tools/README.md) — choose the simplest safe execution mechanism for each task.
5. [Agents and Business Workflows](week05-agents-workflows/README.md) — determine when bounded autonomy earns its operational complexity.
6. [Governance, Security, Evaluation, and Observability](week06-governance-observability/README.md) — make AI behavior trustworthy, measurable, and controllable.
7. [Scale, Reliability, and Economics](week07-scale-reliability-economics/README.md) — keep the platform reliable and economically sustainable as usage grows.
8. [Integrated Enterprise Architecture](week08-enterprise-architecture/README.md) — synthesize, communicate, and adapt the complete architecture.

## Daily Folders

Daily folders use a lowercase, zero-padded sequence and descriptive slug:

```text
day01-topic-name/
day02-topic-name/
```

A daily folder is created only when its lesson begins. This keeps the repository aligned with completed work rather than anticipated content.

Each lesson normally links its detailed HTML lesson to global [ADRs](../adr/README.md), [cheat sheets](../cheatsheets/README.md), [system designs](../system-designs/README.md), [HealthSure updates](../case-studies/healthsure/README.md), [open questions](../open-questions/README.md), and [architect reflections](../architect-journal/README.md). These shared artifacts preserve decisions and learning across week boundaries.

See the full [two-month roadmap](../ROADMAP.md) for program rationale and exit criteria.
