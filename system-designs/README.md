# System Designs

This directory contains decision-relevant architecture diagrams and their narratives. A design should identify boundaries, responsibilities, data and control flows, authoritative sources, trust boundaries, failure paths, operating ownership, important assumptions, and links to supporting ADRs.

Diagrams must be accompanied by enough narrative to explain why components exist and what would change the design. Avoid decorative detail that does not affect a decision.

Version HealthSure designs as `healthsure-v01-description.*`, incrementing the version only when an accepted architectural change occurs. Record the trigger in the HealthSure architecture-evolution log.
