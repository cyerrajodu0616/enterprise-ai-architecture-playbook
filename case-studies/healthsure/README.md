# HealthSure Insurance Case Study

HealthSure is a fictional regulated insurance enterprise used to make architectural trade-offs visible over time. It begins with a narrowly scoped internal policy knowledge assistant and evolves only when business outcomes, evidence, risk, or operating needs justify change.

- [Business context](business-context.md)
- [Current state](current-state.md)
- [Architecture evolution](architecture-evolution.md)
- [Open decisions](open-decisions.md)

HealthSure is a learning model, not a prescribed reference architecture. Every decision remains conditional on documented assumptions and review triggers.
