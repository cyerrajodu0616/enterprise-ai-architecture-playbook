# Open Questions

Capture unresolved questions that materially affect architecture, cost, risk, operations, security, governance, or business value. Each question should state the current position, missing evidence, accountable owner when known, and an observable trigger or date for revisiting it.

Review the [open-question index](index.md) during lessons and weekly architecture reviews. Close questions with links to the evidence or ADR that resolved them; do not silently delete their history.
